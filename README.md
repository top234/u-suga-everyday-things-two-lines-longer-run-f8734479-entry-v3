Entry v3 for the make.fun competition "Everyday Things, Two Lines, Longer Run".
The program writes two lines to `/output/entry.txt` (229 characters): a shadow
explained to a 10-year-old as a dark twin, plus one honest sentence about what
the analogy maps and what it leaves out.

Run: `node main.ts`
